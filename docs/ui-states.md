# Hi-Fi UI states

The gallery below documents the states used for the Lumen shell pass. Capture
each state from the running application at a 1600px-or-smaller window width.

1. **Idle Personal two-pane DDG + QA** — Open a DDG tab, split right, and open
   the QA surface. [Screenshot](ui/1-idle-personal-two-pane.png)
2. **Sidebar row hover** — Move the pointer over a tab row without selecting
   it. [Screenshot](ui/2-sidebar-row-hover.png)
3. **Sidebar row selected** — Select a tab in the sidebar. [Screenshot](ui/3-sidebar-row-selected.png)
4. **Agent running pulse** — Start an agent and capture its running state.
   [Screenshot](ui/4-agent-running-pulse.png)
5. **Agent failed** — Trigger or open a failed agent run.
   [Screenshot](ui/5-agent-failed.png)
6. **Command bar open** — Open the search/command bar.
   [Screenshot](ui/6-command-bar-open.png)
7. **Address field focused** — Focus a pane address field.
   [Screenshot](ui/7-address-field-focused.png)
8. **Pane unfocused vs focused** — Show adjacent panes with focus moved between
   them. [Screenshot](ui/8-pane-focus.png)
9. **Divider hover** — Hover a split divider.
   [Screenshot](ui/9-divider-hover.png)
10. **Space switch** — Open the space switcher and select another space.
    [Screenshot](ui/10-space-switch.png)
11. **Empty sidebar section** — Show a section with no matching rows.
    [Screenshot](ui/11-empty-sidebar-section.png)
12. **Dark mode** — Switch the appearance to dark mode.
    [Screenshot](ui/12-dark-mode.png)
